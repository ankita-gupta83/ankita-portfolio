- Fully Responsive Design

## Installation & Setup

Clone the repository:

```bash
git clone https://github.com/ankita-gupta83/ankita-portfolio.git
```

Navigate to project folder:

```bash
cd ankita-portfolio
```

Install dependencies:

```bash
npm install
```

Start development server:

```bash
npm run dev
```
